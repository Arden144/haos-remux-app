# Home Assistant App: Remux

Run [Remux](https://github.com/lostb1t/remux), a Jellyfin-compatible media server, on Home Assistant.

The app uses the upstream multi-architecture Remux image, exposes port 3000 for the Remux dashboard and Jellyfin-compatible clients, and mounts Home Assistant media read-only at `/media`.

See [DOCS.md](DOCS.md) for setup and account behavior.
